# Android automation links

PlezyNG registers Android `ACTION_VIEW` handlers for `plezy://` links. They can launch media, switch to an existing profile, or control an active video session.

## Link forms

| Link | Action |
| --- | --- |
| `plezy://watch?...` | Resolve and play a movie or a show's next/shuffled episode from connected Plex, Jellyfin, or Emby servers. Copy a generated link from a movie or show detail page. |
| `plezy://profile?id=<profile-id>` | Switch to a local or Plex Home profile. Copy this from that profile's detail page. Normal local PIN and Plex Home PIN checks still apply. |
| `plezy://control?command=play` | Resume the active video session. |
| `plezy://control?command=pause` | Pause the active video session. |
| `plezy://control?command=toggle` | Toggle play/pause on the active video session. |
| `plezy://control?command=stop` | Stop the active video session and leave the player. |

`control` links only address the active video player; they cannot start arbitrary content. A `watch` link can be generated from the media detail page and is resolved against the connected servers. The profile detail screen provides a copy action for the profile URI.

## Launch from Android Debug Bridge

The Android shell can open any registered link directly:

```sh
adb shell am start -a android.intent.action.VIEW -d 'plezy://control?command=pause'
```

Replace the URI with a generated watch or profile link. Query values must be URL-encoded when constructing links manually.

## Home Assistant

Home Assistant's [Android Debug Bridge integration](https://www.home-assistant.io/integrations/androidtv/) can send ADB shell commands to Android TV and Fire TV devices. Enable ADB debugging on the device and authorize Home Assistant's connection first. The integration's [`androidtv.adb_command` action](https://www.home-assistant.io/actions/androidtv.adb_command/) accepts an ADB shell command.

For example, this script pauses the current Plezy video on an Android TV device:

```yaml
script:
  pause_plezy:
    alias: Pause Plezy
    sequence:
      - action: androidtv.adb_command
        target:
          entity_id: media_player.living_room_tv
        data:
          command: am start -a android.intent.action.VIEW -d 'plezy://control?command=pause'
```

To play media, pass a `plezy://watch` URI generated by Plezy in the same command. To change profiles, use the profile URI copied from its detail page; if that profile is protected, complete the PIN prompt on the device before sending a separate watch link.

This is an Android intent bridge. It does not register Plezy as a native Plex Companion client in Home Assistant's Plex integration, whose media-player support targets connected Plex clients. The bridge also does not create a native Plex/Jellyfin/Emby media-player entity in Home Assistant.
