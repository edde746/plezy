# Selective backport ledger

Audit: 2026-09-28; base `1.8.1` / `10d4b3088f009c8c61e1fe1024e3ae99cf147113`; upstream snapshot `a2f85f9b17cdfec8fd5570ecc300b460782c8549`; latest tagged release inspected `2.21.0`.

The entries below are grounded in commit diffs and source files, not only release descriptions. Paths are **at the listed commit**, often different from the 1.8.1 path. In particular `lib/services/plex_client.dart` and `lib/utils/endpoint_failover_interceptor.dart` in later releases map to base `lib/client/plex_client.dart` and `lib/network/endpoint_failover_interceptor.dart`.

**No later commit is approved for a blind clean cherry-pick.** Most cross the 1.9 player rewrite, service moves, new profile models, offline support or modern framework APIs. “Manual” means copy the invariant/algorithm and adapted tests, not the complete newer service. New dependencies listed below are what the *original patch* assumes; the GKUI extraction should add none unless explicitly needed. Keep GPL notices and record source commit attribution in implementation commits.

Priority: **MUST** for the relevant milestone to pass; **SHOULD** for reliability/performance; **OPTIONAL** after core gates; **SKIP** incompatible, superseded or outside scope. MUST does not mean implement everything before the first APK.

### Exact minimum extraction from c10cf55f

1. `lib/models/transcode_quality_preset.dart`: keep Original,480p1.5Mbps,720p2/3/4Mbps. Preserve labels via `lib/utils/quality_preset_labels.dart` and only required English/translation keys. Copying all generated translation changes is unnecessary.

3. `lib/services/playback_initialization_service.dart`: carry selected preset, play method, source duration, media/part indexes, headers, play-session/transcode-session IDs and output stream metadata through the result. Introduce a small base-compatible DTO if needed. Exo adapter consumes its URL; no platform rewrite from this commit.
4. `lib/models/plex_media_info.dart`: retain stream IDs and legitimate external subtitle keys. The original sidecar construction must be corrected using f4ce6061 before general subtitle support.
5. `lib/services/settings_service.dart`, `lib/providers/settings_provider.dart`, `lib/screens/settings/playback_settings_screen.dart`: one persisted quality default, initially720p3Mbps. `lib/widgets/video_controls/sheets/version_quality_sheet.dart` and `track_controls_state.dart`: only quality selection/renegotiation, adapted into the smaller base UI.
6. `lib/services/plex_auth_service.dart` and `multi_server_manager.dart`: pass conservative client capabilities into every Plex client. Keep discovery/TLS policy centralized. Omit downloads, offline sync, Live TV and backend-generalization additions elsewhere.

Important inspected behavior: tagged VOD code uses `/video/:/transcode/universal/decision` and `/video/:/transcode/universal/start.m3u8`; its extensionless `/start` usage is Live TV. The profile targets HLS/MPEG-TS with `h264%2Chevc` and AAC: **remove HEVC**. The enum's resolution values are not sufficient to constrain output; apply and verify explicit resolution/profile/channel limits. Original sets directPlay/directStream, lower presets request conversion; `location=lan` must be reviewed for remote use. Unknown decision codes and “transcode failed -> original” fallback are unsafe unless the independent GKUI capability check passes. Keep explicit session IDs and token forwarding, not only a constructed URL.

Required tests before claiming M7: inspect server-returned video/audio codec, dimensions, bitrate, play method and session; decision/start parameter equivalence; refusal/no transcoder; token expiration; subtitle burn; seek/resume/timebase; session cleanup. No authenticated PMS test was performed in this audit.

## Implementation ordering and tests

1. **M0:** no broad backports. Minimal compatible theme, bounded lazy diagnostics, secret-safe logging.
2. **M1–M3:** HTTPS candidate policy; PIN error/expiry handling; profile race/required selection and shared-resource token ownership; invalid-token termination; identity-aware bounded failover; resume/offline recovery; stale/late-result cancellation and cleanup.
3. **M4:** library initialization and partial loading, server/profile-scoped events, resized artwork, decode/cache/concurrency limits, token-free cache metadata.
4. **M5–M6:** player abstraction, request headers, audio focus, loading/failed exit, exact resource ownership, source timebase, timeline session IDs.
5. **M7–M8:** narrowed c10cf55f protocol model plus the *final* HLS seek semantics, refusal handling, selected audio, external text and embedded-burn subtitle handling.
6. **M9:** stress memory, stalled network, repeated failed-open/retry, sleep/resume and image/log viewers. Do not copy desktop/TV buffer or image-cache numbers without measurements.

Use fake Dio transports and controllable Futures to reproduce token401 versus offline, out-of-order login/profile responses, old-generation endpoint failures, shared-server tokens, wrong machineIdentifier, sign-out during refresh, timeout then late client completion, permit release after body stall, and duplicate seek offsets. Retain adapted upstream tests where possible; avoid broad fixture/database imports. Public Plex endpoints and user PMS/hardware tests are separate integration gates.
